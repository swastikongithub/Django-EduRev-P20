# Food photos (not committed)

This folder holds the website's food photography as optimised WebP files, for example
`thali-spread-1024.webp`. The photos are licensed from **Adobe Stock** (free collection, Standard licence).
The licence allows them on the FoodLoop website but not as standalone downloadable files, so they are
**kept out of the public Git repository** (see `foodloop/.gitignore`).

- **Get them:** unzip `foodloop-photos.zip` (sent separately) into this folder.
- **Without them:** every image falls back to FoodLoop's built-in illustrations, so nothing breaks.
- **Which photo is which:** `docs/image-credits.md` lists every file with its Adobe Stock ID.
