For integrators: push from P13

The timetable system can publish directly. A service account with timetable rights sends the whole term; it's validated and published in one transaction, or rejected with every row error (HTTP 422) and nothing changes.

POST /api/v1/timetable/publications/
Content-Type: application/json

{
  "term": "{{ terms.0.code|default:'26271' }}",
  "entries": [
    {"room_code": "34-301", "day": "Mon",
     "start": "09:00", "end": "10:00",
     "course_code": "CSE326", "section": "K23KF",
     "faculty": "Dr. A. Sharma", "kind": "Lecture"}
  ]
}

Returns 201 with the publication, occurrences and displaced counts. Full schema in the API docs.
